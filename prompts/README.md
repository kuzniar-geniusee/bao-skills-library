# Prompt Templates

Lightweight prompt templates for one-off BA tasks that don't need a full skill.

*Templates will be added here as they are documented.*

---

| Template | Phase | Description |
|---|---|---|
| Stakeholder Q&A log | 2 · Discovery | Structures open questions + client answers into a running Confluence table |
| Validate meeting notes | Iterative | Converts raw meeting notes into decisions / action items / open questions |
| System Prompt template | 1 · Project Setup | Depersonalized System Prompt (Project Instructions) — generic framework layer + project placeholders |
| Create System Prompt | 1 · Project Setup | Fills the System Prompt template from a project description |
